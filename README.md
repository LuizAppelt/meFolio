# ⚡ meFolio — Personal Bio & Bento Grid Portfolio

> Uma plataforma moderna e ultra-personalizável de Link na Bio e Portfólio interativo inspirada no **Bento Grid** (`bento.me` / `own.page`).

![meFolio Banner](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?q=80&w=1200&auto=format&fit=crop)

---

## ✨ Principais Funcionalidades

- 📱 **Layout Bento Grid Responsivo**:
  - Proporção visual e alinhamento de blocos `1x1`, `2x1`, `1x2`, `2x2` e `full`.
  - Arraste e solte (*Drag & Drop*) intuitivo para reorganizar os blocos em tempo real.
  - Modo de Edição Visual direto na grade com redimensionamento dinâmico.

- 🎵 **Central de Áudio & Música Multi-Fonte**:
  - **Upload de MP3 do PC**: Carregue arquivos de áudio locais para tocar nativamente.
  - **Spotify Embed**: Suporte ao código oficial de incorporação (`<iframe>`) com streaming.
  - **YouTube Áudio**: Prévia de áudio com capa e controles dedicados.
  - **4 Presets Prontos**: Trilhas relaxantes de Lofi, Synthwave e Acústico em 1 clique.
  - Equalizador visual com ondas sonoras e controle deslizante de volume.

- ⚡ **Integração Automática com GitHub**:
  - Importação de repositórios com 1 clique através da API pública do GitHub.
  - Preenchimento automático de estrelas ⭐, forks 🍴, linguagem, descrição e banners OpenGraph.
  - Upload de screenshots do projeto direto do computador.

- 🎨 **Estúdio de Temas & Customização Total**:
  - **8 Temas Prontos** com alto contraste (WCAG 4.5:1).
  - Criador de Temas Customizados com texturas (Mesh, Dots, OLED, Noise, Glassmorphism).
  - Catálogo com mais de **10 fontes tipográficas** (Google Fonts).
  - Tags de habilidades coloridas e ícones de redes sociais com as cores oficiais das marcas.

- 📊 **Analytics Privado**:
  - Contagem de visitas à página, cliques por card, cópias de chave Pix e mensagens.

- 🔒 **Persistência & Backup Local**:
  - Salvamento automático em tempo real no `localStorage`.
  - Exportação e importação completa em arquivo `.json`.

## 🛠️ Tecnologias Utilizadas

- **React 19** + **TypeScript**
- **Vite** (Build ultrarrápido)
- **Tailwind CSS** (Design responsivo & Glassmorphism)
- **Framer Motion** (Animações suaves e transições fluidas)
- **Lucide Icons** (Ícones modernos)
- **Canvas Confetti** (Micro-interações de feedback)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/LuizAppelt/meFolio.git
   cd meFolio
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abra no navegador:**
   `http://localhost:5173`
